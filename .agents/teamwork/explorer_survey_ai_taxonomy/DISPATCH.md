   - Conditioning variables, prompt weighting, negative prompts, camera motion tokens (pan, tilt, zoom, truck, pedestal, roll, orbit, arc, crane), focal length, aperture/depth of field, shutter speed/angle, lighting styles (chiaroscuro, Rembrandt, volumetric, golden hour, neon, rim light), color science/LUTs, rendering styles, temporal coherence, frame rate, motion scale, seeds, resolution, aspect ratio, audio sync, sound design.

   - Determinant attributes for each product: target audience, intent/purpose, platform, duration, resolution, aspect ratio, visual style, pacing/rhythm, narrative structure, audio/voiceover, subtitles.
   - Guidelines for translating informal user intentions into structured prompt specifications for AI/LLM models.

     * se diferencia de / se diferencia de

     * tiene como resultado / es resultado de
4. Design the Schema & JSON-LD architecture:
